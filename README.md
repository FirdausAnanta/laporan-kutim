# Laporan Kutim · Selara OS Presentation

Presentasi interaktif berbasis web (macOS workspace style) untuk laporan dan tinjauan program Festival Literasi Kutai Timur (FL Kutai Timur) oleh Nyalanesia.

## Fitur Utama
- **Wallpaper Resmi:** Foto Rapat Koordinasi FL Kutai Timur.
- **Top Bar:** Glassmorphism dengan identitas resmi Nyalanesia dan live digital clock.
- **3 Aplikasi Dock Utama:**
  1. **Program:** Ringkasan & visi, portofolio program (GSMB, FLD, SLN, NTA, AMB), alur pelaksanaan, capaian, manfaat, dan langkah strategis.
  2. **Acara Puncak:** Konsep & esensi selebrasi, rangkaian agenda (rundown), rekam jejak festival daerah, penganugerahan rekor & piala, serta standar panggung VVIP.
  3. **Publikasi:** Ekosistem penerbitan digital NyalaPress, alur naskah ke buku, kurasi resmi Puspresnas, pencetakan & logistik, serta perlindungan hak cipta & royalti.
- **Jendela Interaktif:** Traffic lights control (tutup, minimalkan ke dock fan, layar penuh), tab navigasi, dan galeri bukti dokumen.

## Cara Menjalankan
Buka berkas `index.html` langsung di peramban web modern apa pun (Chrome, Safari, Edge, Firefox).
Atau aktifkan **GitHub Pages** melalui menu `Settings > Pages` pada repositori ini.
